# NØMAD Shopify Theme

Custom Shopify Online Store 2.0 theme for NØMAD.

## Image workflow

Hero and quality images are selected inside Shopify Theme Customize, so they do not need to be hard-coded into the repository. Product cards automatically use the first product image and swap to the second image on hover.

## Required Shopify pages

Create these pages in Shopify and assign the matching templates:

- Contact Us → template `contact`
- Track Order → template `track-order`

The T-Shirts navigation points to `/collections/t-shirts`.
